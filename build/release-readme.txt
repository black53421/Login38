Login38 — 天堂 3.8 登入器
========================================

這包裡有兩個程式:

  launcher.exe    玩家用的登入器。放進客戶端目錄,取代原本的登入程式。
  encoder.exe     伺服器主用的編碼工具。產生 launcher.exe 要讀的設定檔。


必要環境
----------------------------------------

  .NET 10 桌面執行階段 — x86 版本

  下載: https://dotnet.microsoft.com/download/dotnet/10.0
  選 "Windows Desktop Runtime" 的 x86 (32-bit) 安裝檔。

  必須是 x86,不是 x64。登入器要注入 32 位元的遊戲行程,
  64 位元的執行階段載不進去。兩個都裝也可以,但 x86 那個不能少。


伺服器主:第一次設定
----------------------------------------

1. 執行 encoder.exe。
2. 在「客戶端」頁填伺服器名稱、IP、連接埠,以及要開的功能。
3. 存檔。encoder 會產生:

     list.txt          加密後的伺服器清單     -> 跟 launcher.exe 放一起發給玩家
     config.ini        功能開關與連結         -> 跟 launcher.exe 放一起發給玩家
     pack.properties   RSA 金鑰(私鑰在裡面)  -> 放到伺服器的 ./config/ 目錄

   pack.properties 絕對不要發給玩家,也不要上傳到任何公開空間。

4. 要自訂變身檔的話,在「變身檔」頁把 .txt 打包成 .pak,
   一併放進發給玩家的資料夾。


玩家:安裝
----------------------------------------

把下面這些檔案放進天堂客戶端目錄(有 Lin.bin 的那一層):

    launcher.exe
    list.txt          伺服器主提供
    config.ini        伺服器主提供
    *.pak             伺服器主提供(有自訂變身檔才需要)

執行 launcher.exe。第一次跑會自己產生 launcher.ini,
記你自己的視窗模式等偏好設定,不用手動建。


常見問題
----------------------------------------

雙擊沒反應 / 跳出要裝 .NET
    x86 版的 .NET 10 Desktop Runtime 沒裝,或只裝了 x64。見上面「必要環境」。

開起來但伺服器清單是空的
    list.txt 不在 launcher.exe 旁邊,或是別台伺服器的 encoder 產生的。
    金鑰不同就解不開,要跟伺服器主拿正確的那份。

登入器開得起來,遊戲起不來
    確認 launcher.exe 在客戶端目錄裡面,不是捷徑指過去。
    登入器是用相對路徑找 Lin.bin 的。

變身檔沒作用
    .pak 必須由同一支 encoder.exe 打包。第三方或舊版的 .pak 會被拒絕。
